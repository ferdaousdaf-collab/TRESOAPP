Cahier de modification rapide
À conserver : ne jamais supprimer le script __TRESO_DATA__, car il contient les données embarquées dans le fichier HTML.
Sauvegarde recommandée : avant chaque grande modification, télécharger une copie portable et un backup JSON.
Fonctions sensibles : loadDB(), saveDB(), copiePortable(), reportUnpaidFromPrevious(), sendDailyReport().

Portabilité — Données avec le fichier
Rendez votre application portable : les données voyagent avec le fichier HTML.
Copiez le fichier sur une clé USB ou un autre PC → vos données sont dedans.
Option A — Lier le fichier (Chrome/Edge uniquement) :
Cliquez "Lier le fichier" → sélectionnez ce fichier TresoApp sur votre disque → acceptez la permission.
Désormais chaque modification sauvegarde directement dans le fichier.

Option B — Copie portable (tous navigateurs) :
Cliquez "Télécharger copie portable" → un fichier HTML avec toutes vos données est téléchargé.
Remplacez l'ancien fichier par cette copie. Faites-le après chaque session.
Sauvegarde & Restauration JSON
La restauration remplace TOUTES les données actuelles. Faites un backup avant.
Notification des paiements du jour
Une application HTML seule ne peut pas envoyer automatiquement un message sans serveur. Le bouton prépare le message et ouvre votre Email ou WhatsApp pour l’envoi.
